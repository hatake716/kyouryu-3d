# 化石表面の表現 — 1.10.0

1.10.0では、独自復元96種類とパタゴティタンの計97モデルに、種類ごとの化石の表面表現を追加しました。赤褐色・暗褐色・砂色・灰黒色などの骨肌に、鉱物の染み、細いひび、粒子状の凹凸、部分的な付着土を重ね、艶を抑えています。個別3D観察とシアターで同じ種類の表面を使用し、図鑑一覧の骨格にも色調を反映します。

色合いと付着土は本アプリ独自の観察用表現で、実際の標本・産地の色を測定したものではありません。トリケラトプス、ティラノサウルス、カルノタウルスは元の公開資料の表面表現を使用します。

## 種類ごとの違い

8系統の色調を土台に、IDから安定した色の差・模様の位置・風化の密度・土の量・粗さを設定します。97モデルにはそれぞれ別の色と模様を割り当て、一覧の順番変更、画面回転、再起動で模様は変わりません。特定の産地の保存色を当てはめた分類ではありません。

| 表現例 | 色調・付着物 |
|---|---|
| スピノサウルス | 赤褐色の骨肌、赤土の染み |
| ヴェロキラプトル | 暗褐色の骨肌、黄土の付着 |
| ブラキオサウルス | 砂色の骨肌、褐色の鉱物斑 |
| ステゴサウルス、パタゴティタン | 栗褐色の骨肌、灰土の付着。模様と色の細部は別 |
| アーケオプテリクス、モササウルス | 灰黒色の骨肌、明るい砂粒。模様と色の細部は別 |
| アンキロサウルス | 黒褐色の骨肌、淡い鉱物斑 |

## 描画

`FossilMaterials.kt` が色・ひび・土・粗さを管理し、`FossilSurface.kt` の共通GLSLを個別3Dと館内の両方から使用します。モデル座標上の連続的な3Dノイズを使うため、UV境界の継ぎ目を追加せず、回転・移動でも模様は骨に固定されます。館内の拡大縮小の前の座標を使い、個別観察と同じ模様の配置を保ちます。照明は各画面の環境に従うため、見かけの明るさは異なります。

大きな色むら、鉱物斑、微細な粒、孔状の暗部、断続的な細い割れ目、付着土を重ねます。土の分布はノイズと割れ目・孔のマスクによる表現で、形状解析や堆積シミュレーションではありません。微小凹凸は法線へ反映し、強い鏡面反射を抑えています。表面の微細な孔・割れ目をメッシュに掘り込む処理ではありません。

画素より細かくなる凹凸は距離に応じて抑制し、見回し時のちらつきを減らします。OpenGL ES 2.0の微分拡張が使えない場合も色と土の表現は表示し、法線の微細凹凸だけを省略します。追加の大きな画像・ダウンロード・権限は不要です。一覧カードは種ごとの色調を簡略表示します。

個別3D画面を閉じる際に描画用のバッファ・表面画像・シェーダーを明示的に解放し、全画面切り替えや画面回転を繰り返す際のメモリ増加も抑えています。

## 公開モデル・資料の扱い

トリケラトプス・ティラノサウルス・カルノタウルスの元のテクスチャと館内用の頂点色を保持します。表面画像を持たないパタゴティタンには今回の表現を適用し、基礎モデル・派生メッシュのCC BY-SA 4.0と作者表示を継続します。独自の表面生成コードはApache 2.0です。外部の写真・有料素材・第三者テクスチャを新たに使用していません。

100種類の原メッシュ、館内用メッシュ、計測値、館内のメートル換算、出典画像は変更していません。観察用の質感改善であり、模式部分の解剖学的精度を引き上げたという意味ではありません。アプリの「モデルと実寸資料」に各種の表面の説明を表示します。

試験結果と最終成果物は [検証記録](VERIFICATION.md) を参照してください。
