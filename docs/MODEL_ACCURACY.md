# 骨格モデル・寸法・表面の資料（1.10.0）

確認日：2026-09-07〜08。収録100種類のうち、**4種類を詳細な公開メッシュで表示**します。実寸単位を確認できたトリケラトプス、展示レプリカの撮影に由来するティラノサウルス、作者の復元であるカルノタウルスとパタゴティタンです。残る**96種類も生成形状を改良**し、うち18種類は選択した骨の実測長を反映、78種類は実測によらない模式復元です。全100種類が同じ標本精度になったという意味ではありません。

## トリケラトプス：公開標本の形状と表面

Smithsonian Institution / National Museum of Natural History の *Triceratops horridus Marsh, 1889*。Smithsonian Open Access の公開S3から、149,998三角形・102,235共有頂点のGLBと単位情報を取得しました。原データの座標・法線・UV・色・陰影（ambient occlusion）・法線マップを保持しています。頂点は描画用に展開するため449,994頂点です。取り込み時の追加の間引き、骨の移動・形の補作はしていません。

- [Smithsonian標本ページ](https://3d.si.edu/object/3d/triceratops-horridus-marsh-1889:d8c623be-4ebc-11ea-b77f-2e728ce88125)
- [公式の原GLB](https://smithsonian-open-access.s3-us-west-2.amazonaws.com/3d/d8c623be-4ebc-11ea-b77f-2e728ce88125/resources/Triceratops_horridus_Marsh_1889-150k-4096.glb)
- [単位を記載した公式scene metadata](https://smithsonian-open-access.s3-us-west-2.amazonaws.com/3d/d8c623be-4ebc-11ea-b77f-2e728ce88125/scene.svx.json)：sceneとmodelの単位は `m`。
- CC0 1.0。[Smithsonian Open Access FAQ](https://www.si.edu/openaccess/faq)、[同標本のCC0表示を保存したCommons固定版](https://commons.wikimedia.org/w/index.php?title=File:Triceratops-full_resolution-obj_(Smithsonian_Institute).stl&oldid=881096487)。
- [取得URL・SHA-256・変換内容・出力ハッシュ](specimen-provenance.json)。

元GLBの軸を `(Z,X,Y)` に回転し、表示の中心を原点へ移動します。最大方向の幅を描画空間の8単位へ合わせ、変換係数 `metresPerUnit` を保存します。変換を戻したモデルの前後幅は **5.891464 m**、高さ **2.803518 m**、左右幅 **1.661696 m**。これは公開メッシュの境界幅で、生体の全長や発見個体の確定値ではありません。複合・補作を含む組み立て復元骨格です。

公開データに骨ごとの領域分けはないため、部位選択は三角形の位置による簡易分類です。隣接部の境界が完全には一致しません。角と襟飾りは頭骨に含めます。標本の色・修復跡も元データを受け継ぎ、生前の骨の色を主張しません。

4096pxのJPEGテクスチャ3点はバイト単位で未改変のまま同梱し、GPUへは通常2048pxとミップマップで読み込みます。OpenGL ES 2.0で標準微分拡張を利用できる端末は法線マップを使い、対応しない端末では幾何法線・色・陰影へフォールバックします。

## 18種類：公表された骨長を表示に反映

[測定値・標本番号・表番号の一覧](bone-measurements.json)。長さは論文のmmをmへ換算し、骨の長軸方向の両端面の距離として形状に反映します。骨幹の湾曲や断面は推定であり、表にある最大長だけから骨表面を正確に復元できるわけではありません。最大長の軸を関節の中心間距離として計測した値とはみなしていません。画面の姿勢は観察用の組み立てです。

Persons, W. Scott IV; Currie, Philip J. (2016), *An approach to scoring cursorial limb proportions in carnivorous dinosaurs and an attempt to account for allometry*, Scientific Reports 6, 19828, **表1、CC BY 4.0**。[原論文](https://doi.org/10.1038/srep19828)。この研究の既存標本名と計測を使用し、近年の分類の全変更を一律に適用した計測表ではありません。

コエロフィシス、ディロフォサウルス、ヘレラサウルス、ケラトサウルス、アクロカントサウルス、アロサウルス、コンカヴェナトル、コンプソグナトゥス、シノサウロプテリクス、アルバートサウルス、ダスプレトサウルス、ドリプトサウルス、ゴルゴサウルス、タルボサウルス、デイノニクス、ミクロラプトル、ヴェロキラプトルの17種類で、大腿骨・脛骨・第III中足骨の値を使用します。分類の再帰属が問題となるTroodonの旧データ、複数標本をまとめたYutyrannusの行は採用していません。

Maidment, Susannah C. R.; Brassey, Charlotte A.; Barrett, Paul M. (2015), *The Postcranial Skeleton of an Exceptionally Complete Individual of the Plated Dinosaur Stegosaurus stenops*, PLOS ONE 10(10), e0138352, **表3、CC BY 4.0**。[原論文](https://doi.org/10.1371/journal.pone.0138352)。

ステゴサウルスのNHMUK PV R36730（Sophie）：右大腿骨868mm・左857mm、右脛骨498mm・左495mm、右第III中足骨100mm、右上腕骨450mm、右橈骨312mm、右尺骨412mm。尺骨は橈骨より長い肘頭側を設けます。左右別の値がない骨は片側の値を反転して補作します。頸椎・背椎・骨板の計測表や同論文の3D PDFも調査しましたが、今回の表示に計測値を反映した部位は上記に限定しています。

特定の標本の寸法であり、成長段階・個体差・属内の全種を代表する固定値ではありません。模型全体の大きさは大腿骨を基準に換算し、頭骨・胴・尾など未計測部の実寸精度を保証しません。

計測表には以前の表示に使ったティラノサウルスCM 9380も保存しているため19行あるが、1.5.0の表示はRigstersの別のレプリカであり、この骨長を重ねて適用しない。

## 共通の立体表現

96種類の生成モデルでは、骨幹を連続した楕円断面でつなぎ、骨端のふくらみ、非対称な断面、滑らかな法線を設けました。肋骨は補間曲線で連続させ、椎骨には椎弓で囲まれた空隙と突起、肩甲骨・腸骨には板状の面を設けています。1.5.0では頭骨を内外の骨壁と実際に空いた開口部で構成し、上下の歯列、曲がった歯冠、骨端の一対の隆起と溝、向きの変わる頸椎、尾の血道弓、厚みのある骨板を追加・改良した。コレクションのサムネイルも同じ三角形メッシュから描画する。これは共通の復元処理で、各分類群の正確な骨数やすべての解剖学的特徴を再現したものではありません。

1.10.0では、独自復元96種類とパタゴティタンの計97モデルに、種類ごとの化石の表面表現を追加しました。赤褐色・暗褐色・砂色・灰黒色などの骨肌に、鉱物の染み、細いひび、粒子状の凹凸、部分的な付着土を重ね、艶を抑えています。個別3D観察とシアターで同じ種類の表面を使用し、図鑑一覧の骨格にも色調を反映します。 色合いと付着土は本アプリ独自の観察用表現で、実際の標本・産地の色を測定したものではありません。トリケラトプス、ティラノサウルス、カルノタウルスは元の公開資料の表面表現を使用します。 [詳細](FOSSIL_SURFACES.md)。テクスチャのないモデルの近接陰影は既存の深度画像方式を継続しています。

個別の「3D骨格」観察画面では、実寸情報がある19種類の床の格子をm単位で表示します。端末画面を物理的な1:1表示にする機能ではありません。この個別画面では81種類を縮尺未確認のモデルとして扱います。1.7.0の館内展示には別途推定全長・翼開長の換算を採用し、根拠を表示します（下記参照）。

## 再生成

```sh
# Python + numpy。入力GLBは上記の公式URLから取得する。
python tools/models/import_specimen.py artifacts/research-models/Triceratops_horridus_Marsh_1889-150k-4096.glb
# 取得済み原論文XMLから測定値とModelEvidence.ktを再生成する。
python tools/models/build_measurements.py
```

原XMLの取得先は `tools/models/README.md`。非商用限定の博物館素材や配布条件の不明なダウンロードを、今回の商用再配布向け素材として採用していません。スキャンの提供元への推薦・提携を示しません。

## 採用しなかった候補

収録100属名と骨格を組み合わせて公開資料を調査した。非商用限定のモデル、使用条件に矛盾のある派生物、別属の骨を誤って当てはめる必要がある資料は同梱していない。大阪市立自然史博物館のアロサウルス（CC BY 4.0）とArtecのステゴサウルス（CC BY 4.0）は権利表示を確認したが、今回の取得経路では同梱用原データを取得できていない。Sophie論文の3D PDFの埋め込みはPRC形式で、U3Dデコーダーで読めるデータではなかった。パラサウロロフスRAM 14000のCC BY表面データは若い個体の片面・母岩付き標本で、全身復元の代替として採用していない。MebaLabのデイノケイルスは作者がWIPと明記し、頭骨などが未完成のため採用しなかった。無条件に全100種類へ実物標本と同じ精度を約束する材料にはならない。


## 1.7.0の館内縮尺

シアターモードを共通のm単位へ変更しました。標本・実測骨長に由来する19種類の単位を保持し、76種類は図鑑等の推定全長・翼開長に換算、5種類は寸法未確定と表示します。館内の頭尾方向の幅を合わせる近似であり、同梱する模式復元の姿勢や高さまで実測に一致するという意味ではありません。別の公開レプリカにSUE等の寸法を参考値として使う場合も、同じ標本のスキャンと誤認させないよう説明しています。全100点の換算根拠と制約は [THEATER.md](THEATER.md) と [館内の変換台帳](theater-mesh-provenance.json)。個別の観察用メッシュと従来の測定資料は維持しています。
