制定日：2026年9月7日

1. 情報の取得・送信
本アプリは個人情報、位置情報、広告ID、連絡先、写真、音声を取得しません。広告SDK、解析SDK、クラッシュ情報の外部送信機能、アカウント機能はありません。インターネット通信権限も要求しません。

2. 端末内の保存
お気に入りの種類を端末内のアプリ専用領域に保存します。第三者に送信しません。各骨格のお気に入りボタンで解除できます。アプリのデータ削除またはアンインストールでも削除されます。OSのクラウドバックアップはアプリ設定で無効にしています。OSが行う端末移行の挙動は機種に依存します。

3. 外部リンク
利用者がWikipedia、YouTube、参考資料、ライセンスのリンクを押すと、外部アプリまたはブラウザーが開きます。YouTubeには恐竜名等の検索語を渡します。外部サービスはIPアドレスやCookie等を自身の方針に従って扱う場合があります。本アプリから端末識別子やお気に入り情報をリンクへ付加しません。

4. 子どもの情報
本アプリには個人情報を入力・送信する機能はありません。外部リンク先には幅広い内容が含まれるため、必要に応じて保護者の方と一緒に利用してください。

5. 変更
機能や情報の取扱いを変更する際は、アプリと公開ページのポリシーを更新します。

https://github.com/hatake716/kyouryu-3d/issues
個人情報を含むお問い合わせは公開Issueに書き込まないでください。
