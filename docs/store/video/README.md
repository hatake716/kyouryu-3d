## Google Play への登録方法

Play Console の「プロモーション動画」欄は **YouTube の URL のみ** を受け付けます。動画ファイルを直接アップロードすることはできません。

1. このファイルを acesmash@gmail.com の YouTube アカウントへアップロードする。
2. 公開設定は「公開」または「限定公開」にする。**「非公開」は Play Console から参照できません。**
3. 収益化・広告を無効にする。動画の冒頭に広告が入るとストア掲載に適しません。
4. Play Console → ストアの掲載情報 → プロモーション動画 に、その YouTube URL を貼る。

Play ストアでは自動再生時に音声がミュートされます。本動画は無音でテロップのみのため、ミュート再生でも内容が伝わります。

## 撮影・制作の記録

**素材**：署名済みリリースビルド `kyouryu-3d-1.10.1.apk`（versionCode 12）をエミュレータへ導入し、実際に操作した画面です。合成・演出・別素材の差し込みはありません。

**環境**：AVD `kyouryu_promo`（Android 15 / API 35、pixel_6、RAM 6144 MB）。`wm size 1080x1920` + `user_rotation 1` で 1920 × 1080 の横画面、`wm density 420` で screenHeightDp = 411 とし、実機の横画面と同じ compact レイアウト（操作欄が右側）を再現しています。ステータスバーは demo モードで時刻 10:00・電池100%に固定し、横画面では本アプリの実装どおりシステムバーが隠れます。

**コマ撮り**：エミュレータは SwiftShader（ソフトウェア GPU）のため `screenrecord` では実効 10.4 fps しか出ません。そこで 1 コマずつ操作 → 描画完了を待って `screencap` する方式（`shoot30.py`）で **854 枚**を撮影し、1 コマ = 1 フレームとして 30 fps で並べています。fps 変換も補間も行っていません。

**操作は `input motionevent`**：`input swipe` は短距離だとタップ判定になり、視点が動かないどころか展示の図鑑が開いてしまいます。DOWN → 細かい MOVE の連続 → UP を送ることで、最初に touchSlop を一度越えれば以降は数 px 単位で確実に動かせます。1 コマあたり視点 9px・骨格回転 7px・スクロール 9px としました。

**歩行速度**：`TheaterRenderer.onDrawFrame` は 1 フレームの移動量を実時間 `dt` から決めます（`TheaterWorld.move` は `min(dt, 0.1) × MOVE_SPEED 8m/s` = 最大 0.8m/frame）。コマ撮りは 1 コマ約 0.75 秒かかるため、スティックを最大まで倒すと毎コマ上限の 0.8m 進み、数コマで壁や展示台に到達してしまいます。スティックの倒し量を 10%（`walk(power=0.10)`）に絞って 1 コマあたりの前進量を小さくしました。スティック座標は `TheaterView.Controls` の実装どおり、density 420 で中心 (84dp, height−104dp) = (220, 807)、半径 54dp = 142 です。

**補間しない理由**：`minterpolate=mi_mode=blend` を試したところ、隣接コマの UI 文字が二重に重なってゴーストしました（展示名パネルの文字が読めなくなる）。素材のコマ数を増やすことで、補間なしで滑らかさを得ています。

**改善の確認**：隣接フレーム間の平均絶対差を測ると、前版（156 枚を 919 フレームへ引き伸ばし）は 86% のフレームが「前フレームと実質同じ」でしたが、本版は 20%（意図した静止シーンの分）です。

## 再生成

撮影スクリプトと組み立てスクリプトは [tools/video/](../../../tools/video/) にあります（`shoot30.py` / `build30.sh`）。`PROMO_WORK` で作業ディレクトリ、`PROMO_DEVICE` で対象エミュレータを指定します。再撮影する場合は、上記の AVD 設定（1920 × 1080・density 420・横向き）を再現してください。density が 420 でないと横画面が compact 判定にならず、操作欄が画面下部へ回り込んで骨格が小さく表示されます。
