## 確認範囲の限界

全100種類の精密スキャン、専門家の解剖学的監修、全機種のGPU横断試験、長時間の発熱・消費電力測定は実施していません。19種類の実測反映は選択した骨長だけで、他の骨や関節角度には復元が含まれます。80種類は模式復元です。標準微分拡張がないGPUでは色・陰影と幾何法線へフォールバックする実装ですが、その非対応端末での実機検証は未実施です。

Google Playへの提出・審査・公開は行っていません。AABはローカルの提出用成果物です。
